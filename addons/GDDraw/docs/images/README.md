# Documentation Images

Place optimized images used by the packaged user manual in this directory.

- Prefer WebP or compressed PNG when transparency is required.
- Keep screenshots readable in a documentation pane approximately 650 pixels wide.
- Use lowercase descriptive filenames, such as `layers-panel-overview.webp`.
- Preserve Godot's default editor theme unless a page specifically explains theme behavior.
- Add useful alt text in the corresponding Markdown page.

The current manual uses explicit **Screenshot placeholder** callouts. Replace each callout with the finished image during the documentation polishing pass.
